# Foundry Sentinel Design System

Version: 1.0

---

# Design Philosophy

The design language of Foundry Sentinel is inspired by enterprise software rather than consumer applications.

The interface should feel like a professional workstation used by engineers, analysts, and security teams.

The visual identity must communicate:

• Trust
• Stability
• Precision
• Simplicity
• Quiet Confidence
• Security

The interface must never resemble a generic AI chatbot or an AI-generated dashboard.

Every screen should feel intentional, minimal, structured, and timeless.

---

# Visual Style

The UI should resemble products such as:

• Microsoft Azure Portal
• Microsoft Fluent 2
• Linear
• Atlassian Admin
• Apple Human Interface
• Enterprise Internal Dashboards

Avoid trendy visual effects.

Avoid unnecessary decorations.

Whitespace is a design element.

---

# Color Philosophy

Blue is the primary identity of the product.

Blue represents:

• Trust
• Intelligence
• Security
• Reliability

Blue must never dominate the interface.

Instead,

Blue should guide attention.

The interface should remain calm.

# Background System

The application background must never be pure white.

Avoid:

#FFFFFF

as a full-page background.

Instead use a layered enterprise background.

Base Color

#F5F8FC

Overlay Layers

Large radial gradients using

#B0E0E6

and

#87CEFA

with opacity below 12%.

The background should feel smooth, soft and premium.

No hard gradients.

No visible color transitions.

No texture.

No patterns that distract the user.

The background should quietly support the interface.

---

# Glass System

Glass should be extremely subtle.

Glass is not the visual identity.

Use only:

backdrop blur

8px–12px

Background opacity

88–92%

Border

1px

rgba(255,255,255,.40)

Shadow

0 8px 30px rgba(20,40,70,.05)

The user should barely notice the glass effect.

---

# Dashboard Background

The dashboard background must never be plain white.

It must use the layered background system.

The background should include:

Soft Powder Blue

Soft Sky Blue

Very subtle Azure tint

All blurred together.

Opacity should remain below 10%.

The result should feel clean rather than colorful.

---

# Login Background

The login page should use the same visual language as the dashboard.

Both screens should appear to belong to the same product.

Do not redesign the login page independently.

Background elements may include:

Very soft radial gradients

Subtle node network illustration

Vector connection lines

Blueprint grid

Enterprise geometry

These elements should remain below 5% opacity.

The login card must remain the visual focus.

---

# Cards

Cards define the entire application.

Cards should appear lightweight.

Do not create floating panels.

Card Background

rgba(255,255,255,.72)

Border

rgba(255,255,255,.45)

Radius

24px

Shadow

0 8px 32px rgba(40,60,90,.05)

Cards should separate information gently.

Never use thick borders.

Hero Cards may use

24px

# Inputs

Large.

Comfortable.

Rounded.

Subtle border.

# Tables

Large row spacing.

Soft borders.

---

# Charts

Charts should remain minimal.

Avoid rainbow colors.

Azure Blue

Ocean Blue

Soft Cyan

---

# Motion

Motion should be almost invisible.

Duration

150–180ms

Ease

ease-out

Avoid:

Bounce

Elastic

Overshoot

Large transitions

---

# Hover

Hover effects should remain minimal.

Border becomes slightly stronger.

Shadow increases slightly.

TranslateY(-1px)

Nothing more.

---

# Shadows

Shadows should create depth without drawing attention.

Never use dramatic shadows.

---

# AI Feel Prevention Rules

Never create colorful dashboards.

Never use purple.

Never use orange gradients.

Never create glowing UI.

Never use oversized illustrations.

Never create oversized icons.

Never create gaming aesthetics.

Never create startup landing page visuals.

Never generate AI-themed graphics.

Never use excessive blur.

Never overuse gradients.

Never overdecorate empty spaces.

# Final Design Principle

If any design decision feels decorative rather than functional,

remove it.

Less is almost always better.


## Visual Reference Rules

The overall visual language of Foundry Sentinel is permanently based on the approved enterprise dashboard reference.

This reference defines the product's visual identity.

Do not redesign the overall composition.

Do not replace the established visual language with new trends.

Future improvements must refine the existing design instead of creating a different one.

The interface should preserve:

- large clean layouts
- subtle premium spacing
- soft layered backgrounds
- lightweight cards
- minimal shadows
- restrained use of color
- understated glass effects
- enterprise proportions
- Microsoft Fluent-inspired consistency

The objective is evolution, never redesign.
