# Purpose

This document defines the official user interface language and copy standards of VectorVault.

Every visible text string across the application must strictly adhere to these guidelines.

The objective is to present a professional enterprise infrastructure platform for evidence analysis, semantic search, and AI-assisted knowledge operations.

# Navigation & Module Copy Breakdown

## Workspace Chat (AI Workspace)
- **Title:** Workspace Chat
- **Subtitle:** Secure evidence analysis and conversational document search.
- **Actions:** New Conversation, Clear Conversation, Copy Response, Export Conversation.
- **Context Labels:** Retrieved Sources, Supporting Documents, References.

## Workstation
- **Title:** Workstation
- **Sidebar Title:** `VectorVault Workstation`
- **Breadcrumb:** `VectorVault > Workspace > Workstation`
- **Subtitle:** Enterprise knowledge operations & system status overview.
- **Hero Card Title:** System Health
- **Hero Description:** Operational status of local offline node and retrieval pipelines.

## Knowledge Hub
- **Title:** Knowledge Hub
- **Subtitle:** Centralized management of organizational knowledge repositories and retrieval rules.

## Documents
- **Title:** Documents
- **Subtitle:** Ingestion, parsing, and chunk management for enterprise files.
- **Actions:** Upload Documents, Import Files, Reindex, Preview, Remove.

## Vector Index
- **Title:** Vector Index
- **Subtitle:** Local SQLite vector embeddings, index statistics, and similarity search parameters.
- **Actions:** Optimize Index, Verify Embeddings, Maintenance.

## Inference Pipeline
- **Title:** Inference Pipeline
- **Subtitle:** Local model execution, routing policies, latency telemetry, and token management.

## Secure Runtime
- **Title:** Secure Runtime
- **Subtitle:** Zero Trust security controls, input sanitization, prompt injection protection, and audit logs.

## Knowledge Operations
- **Title:** Knowledge Operations
- **Subtitle:** Background tasks, ingestion queues, batch processing, and telemetry monitoring.

# Writing Principles

Every sentence across VectorVault interface must be:
- **Clear**
- **Direct**
- **Professional**
- **Concise**
- **Calm**

Avoid marketing hype, emojis, exclamation marks, or casual gaming/startup language.
