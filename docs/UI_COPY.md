# Foundry Sentinel UX Writing Guide

Version: 1.0

---

# Purpose

This document defines the official user interface language of Foundry Sentinel.

Every visible text across the application must follow these standards.

The objective is to create a product that feels like enterprise infrastructure software rather than a consumer AI application.

The interface should communicate professionalism, clarity, precision, and confidence.

All user-facing content must be written in clear, neutral, international English.

---

# Writing Principles

Every sentence should be:

• Clear

• Direct

• Professional

• Concise

• Calm

Avoid marketing language.

Avoid technical jargon unless required.

Avoid unnecessary adjectives.

Never exaggerate capabilities.

The product should sound trustworthy rather than impressive.

---

# Voice & Tone

The interface should feel like:

Microsoft Azure

GitHub Enterprise

Atlassian Administration

Linear

Apple Business Manager

The tone is:

Professional

Reliable

Quiet

Confident

Helpful

Objective

Never playful.

Never casual.

Never promotional.

---

# Global Language Standards

The application is designed for international organizations.

Never reference:

Countries

Governments

Local regulations

Currencies

Regions

National terminology

Industry examples should remain globally applicable.

Use international English only.

# UX Writing Rules

Use sentence case.

Keep labels short.

Prefer nouns over verbs for navigation.

Avoid technical abbreviations.

Never use exclamation marks.

Avoid emojis.

Never capitalize every word unnecessarily.

Do not use filler words.

Avoid repeating "AI" throughout the interface.

Every screen should feel calm, structured, and intentional.

When in doubt, choose the simpler wording.
